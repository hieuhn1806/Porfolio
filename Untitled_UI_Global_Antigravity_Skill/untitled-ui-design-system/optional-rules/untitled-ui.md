# Web UI design system preference

Whenever generating, implementing, changing, or reviewing frontend UI across projects, read and follow the global skill named `untitled-ui-design-system` in `~/.gemini/config/skills/untitled-ui-design-system/SKILL.md`, unless the user explicitly requests another Design System or project-level rules take precedence. Use its source-derived design tokens and relevant component guidance, without claiming full Figma fidelity. Do not apply this preference to backend-only, non-UI tasks.
