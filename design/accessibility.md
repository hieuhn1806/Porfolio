# Accessibility review target
Use semantic controls, programmatic field labels, landmarks and heading hierarchy. All critical
actions must work by keyboard with visible focus; manage modal focus and return it on close.
Target readable contrast (normal text 4.5:1; large text 3:1) and non-color status cues.
Provide descriptive text alternatives for meaningful images and accessible names for icon buttons.
Associate errors with inputs; announce important asynchronous status changes appropriately.
Respect reduced-motion preference. Test zoom, overflow, long content and touch operation.
Automated checks help but do not replace keyboard/manual review; do not claim full compliance
from an automated score. Document measured checks, tools and unresolved limitations.
